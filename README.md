Employer Risk Index Dashboard

This project focuses on detecting and analyzing fraudulent job postings using data analytics and visualization techniques.

The dashboard was built using:

Power BI
SQL
Python (Pandas)
CSV Dataset
Key Features
Fake vs Real Job Analysis
Fraud Percentage KPI
Industry-wise Fake Job Detection
Employment Type Risk Analysis
Remote Job Fraud Insights
Experience-Level Fraud Trends
Interactive Filters and Slicers
Process
Data Cleaning using Python & Power Query
SQL Queries for analysis
KPI and Measures creation in Power BI
Interactive Dashboard Design
Tools Used
Power BI
SQL
Python
Excel / CSV
Insights Generated
Most fake jobs were found in Full-time roles
Remote jobs showed higher fraud risk
Certain industries had significantly higher fake posting counts
Mid-Senior and Entry-level roles were most targeted
